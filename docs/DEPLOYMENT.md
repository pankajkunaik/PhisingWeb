# Production Deployment Guide: PhishGuard AI

This guide walks you through deploying PhishGuard AI using an enterprise-grade, high-performance architecture:
* **Frontend**: Next.js 16 on **Vercel** (Global Edge CDN, Automatic HTTPS, Zero-CORS Rewrites)
* **Backend**: FastAPI + XGBoost ML Engine on **Render** (Containerized Web Service via `render.yaml`)
* **Database**: Serverless PostgreSQL on **Neon** (Auto-scaling, Connection Pooling, Automatic SSL)

---

## 🏛️ Architecture Overview

```
[User Browser]
       │
       ▼ (HTTPS)
[Vercel: Next.js Frontend]  ➔  (URL Rewrite: /api/*)
                                       │
                                       ▼ (Secure Internal Proxy)
                       [Render: FastAPI + XGBoost Backend]
                                       │
                                       ▼ (SSL Pooled Connection)
                       [Neon: Serverless PostgreSQL DB]
```

---

## 📋 Step 1: Create a Serverless Database on Neon

1. Visit [Neon.tech](https://neon.tech) and sign up for a free account.
2. Click **Create Project**, name it `phishguard-db`, and select your preferred region (e.g. `US East / Oregon` to match your backend region).
3. Copy your connection string (ensure **Pooled Connection** is selected):
   ```
   postgresql://phishguard_user:your_password@ep-cool-cloud-123456-pooler.us-east-2.aws.neon.tech/phishguard_db?sslmode=require
   ```

## 🚀 Step 2: Deploy Backend to Render (1-Click Blueprint)

1. Push your repository to **GitHub**.
2. Log into [Render.com](https://dashboard.render.com).
3. Click **New +** ➔ **Blueprint**.
4. Connect your GitHub repository. Render will automatically detect [`render.yaml`](../render.yaml).
5. In the configuration prompt, provide the following environment variables:
   * `DATABASE_URL`: Paste your Neon connection string from Step 1.
   * `APP_ENV`: `production`
   * `SECRET_KEY`: *(Automatically generated by Render)*
   * `ALLOWED_ORIGINS`: `https://*.vercel.app,http://localhost:3000`
   * `GROK_API_KEY`: *(Optional)* Your xAI Grok API key.
   * `GOOGLE_SAFE_BROWSING_API_KEY`: *(Optional)* Your Google Safe Browsing API key.
6. Click **Apply**. Render will build the Docker container and start your service.
7. Once deployed, copy your backend URL (e.g., `https://phishguard-backend.onrender.com`).

---

## ⚡ Step 3: Deploy Frontend to Vercel

1. Log into [Vercel.com](https://vercel.com).
2. Click **Add New...** ➔ **Project**, and import your GitHub repository.
3. In the project setup:
   * **Framework Preset**: Next.js
   * **Root Directory**: `frontend`
4. Expand **Environment Variables** and add:
   * `BACKEND_API_URL`: Your Render backend URL from Step 2 (e.g., `https://phishguard-backend.onrender.com`).
5. Click **Deploy**.

> [!TIP]
> **Zero-CORS Magic**: Next.js automatically rewrites all `/api/*` browser calls to your `BACKEND_API_URL`. This means your browser makes calls to `https://your-app.vercel.app/api/...`, eliminating all CORS errors, pre-flight latency, and third-party cookie restrictions!

## 🛠️ Step 4: Local Development Quickstart

### Backend
```bash
# 1. Install dependencies
pip install -r backend/requirements.txt

# 2. Train / verify ML model
python ml/train.py

# 3. Run test suite
python backend/app/tests/test_api.py

# 4. Start local daemon
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🐳 Step 5: Full Docker Compose Deployment (Self-Hosted)

For self-hosting on a single VPS (DigitalOcean, Hetzner, AWS EC2):

```bash
# 1. Configure environment
cp backend/.env.example backend/.env

# 2. Launch full multi-container stack (FastAPI + Next.js + Postgres + Redis)
docker compose up --build -d
```
* Frontend accessible at: `http://your-server-ip:3000`
* Backend API accessible at: `http://your-server-ip:8000`
